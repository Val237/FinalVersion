# FinalVersion - Kind RockStars

## 🇫🇷 Français

**Description :**
Kind RockStars est un site web interactif pour enfants, dédié à l'histoire du rock, aux instruments, aux légendes et à l'apprentissage musical de façon ludique.

**Structure du projet :**
```
Features.js            - Fonctionnalités JavaScript
Icon.png              - Icône du site
index.html            - Page d'accueil
Index.js              - Scripts principaux
instrumente.html      - Page des instruments
quizz.html           - Page du quiz musical
quizz.js             - Logique du quiz
robots.txt           - Configuration pour robots
rockstar.html        - Page des rockstars
Rockstar.js          - Scripts pour rockstar
Sitemap.xml          - Plan du site
Stylesheet.css       - Styles CSS

Instrumente/         - Dossier images instruments
  Gitarre.jpeg
  Klavier.png
  Schlagzeug.png
  Singen.png

Rock-Bilder/         - Images rock
  [Images diverses]

sounds/              - Fichiers audio
  [Fichiers MP3]

startseite-bilder/   - Images page d'accueil
  [Images par décennie]

Video/               - Contenu vidéo
  Rock-Video.mp4
```

**Technologies utilisées :**
- HTML5
  - Structure sémantique
  - Éléments audio/vidéo
- CSS3
  - Flexbox
  - Grid Layout
  - Media Queries
  - Animations
- JavaScript
  - ES6+
  - DOM Manipulation
  - Event Handling
  - Audio Controls

**Fonctionnalités :**
- Navigation responsive
- Quiz interactif
- Lecteur audio intégré
- Générateur de noms de groupes
- Galerie d'images
- Timeline historique du rock
